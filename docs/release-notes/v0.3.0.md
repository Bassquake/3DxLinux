## tdxd 0.3.0 — Settings panel and LCD Manager

This release adds the two Windows programs 0.2.0 lacked: the **3DxWare control
panel** and Logitech's **LCD Manager** with its three applets. Everything was
tested on a real SpacePilot Pro (firmware 4.11); see `docs/HARDWARE_TESTS.md`.

### New

**Settings panel (`tdx-settings`).** A GTK 3 port of the 3DxWare 10 control
panel, with the same windows and layout:

- the main window (device, Speed), **Advanced Settings**, **Buttons**,
  **LCD Manager** and **About**;
- it edits `/etc/tdxd.conf` and the per-application profiles, keeps their
  comments, and applies each change with `tdxctl reload`;
- files you can't write are saved through `pkexec` (one administrator prompt);
- the window title switches between the defaults and the per-application
  profiles, or creates one for the focused application.

**LCD Manager (`tdx-lcdmgr`, `tdx-lcdmanager`).** A Linux port of Logitech's
LCDMon, which 3DxWare uses to run applets on the SpacePilot Pro LCD.

- **`tdx-lcdmgr`** runs as your user and takes the LCD over from tdxd. Stop it
  and tdxd's own key page comes back.
- **The LCD keys work as on Windows.** The LCD key opens the program list (in
  the Windows look); UP/DOWN pick a program and OK starts it.
- **`tdx-lcdmanager`** is the LCD Manager window: programs, autostart,
  brightness, contrast, Identify. The **LCD Manager** button in `tdx-settings`
  opens it.
- **Applets** use `libtdxlcd` (C, the same `lgLcd*` functions as Logitech's
  SDK) or `tdxlcd.py` (Python). `tdx-lcd-demo -a` is a small example.

**The three applets**, rebuilt from the Windows ones:

- **Function Keys**: the focused application's name and icon, and what each
  button does, on three pages (keys 1–10, the view keys, the modifier and
  speed keys). It follows app switches and per-application profiles, and shows
  the Speed pop-up for +/−.
- **RSS Feeds**: RSS 1.0/2.0 and Atom feeds; UP/DOWN pick a story,
  LEFT/RIGHT switch feeds, OK opens the story in the browser.
- **Picture Viewer**: a slideshow with the Windows transitions. The MENU key
  opens a small menu with **Configure...**.
- Each has a **Configure...** dialog on the PC.

**Button actions.** `action_<V3DK id> = speed_up | speed_down | dominant |
rotation | panzoom | calibrate | lcd_next` handles a button inside tdxd, like
3DxWare's built-in button functions. The shipped config binds +, −, DOM, ROT
and PAN ZOOM as 3DxWare does.

**The 3DxWare look (optional).** The 3DxWare and LCD Manager artwork belongs
to 3Dconnexion and Logitech and is not included. If you have the Windows
installer, `sudo tdx-extract-3dxware-ui 3DxWare64_v10-9-14_b745.exe` copies it
out once (it only reads files; needs `7z`). The panel, the LCD Manager and the
applets then look like the Windows ones, and the windows get the Windows
programs' taskbar icons. Without it, the same layouts are drawn with plain
shapes.

### Changed

- tdxd writes `/run/tdxd/LCDCfg.xml` (new `lcd_cfg` option), the file the
  Function Keys applet reads, in 3DxWare's format.
- tdxd only sends the LED and LCD brightness settings to a device when they
  change, not on every profile switch or reload.

### Fixed

- `tdxctl reload` or a profile switch could hang tdxd when the device stopped
  answering, for example after a dropped USB-over-network link. Found during
  hardware testing before release.

`tdxd`, `tdx-lcd`, `tdxctl`, `tdx-lcdmgr` and `tdx-lcd-demo` are statically
linked. `tdx-settings`, `tdx-lcdmanager` and the applets are Python 3 with GTK 3:

```bash
sudo apt install python3-gi python3-gi-cairo gir1.2-gtk-3.0
```

(Fedora: `python3-gobject gtk3`.)

### Install or upgrade

```bash
tar xzf tdxd-0.3.0-linux-x86_64.tar.gz && cd tdxd-0.3.0-linux-x86_64
sudo ./install.sh
sudo systemctl restart tdxd   # if it was already running
```

Then, as your user, start the LCD Manager:

```bash
systemctl --user enable --now tdx-lcdmgr
```

An existing `/etc/tdxd.conf` is kept. To get the 3DxWare button functions
(+, −, DOM, ROT, PAN ZOOM) and the Function Keys applet, add the new
`action_…` and `lcd_cfg` lines from the `tdxd.conf` in the archive.
